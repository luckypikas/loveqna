## 📌 Project Overview
Welcome to the core repository for **LoveQnA**. This repository houses the front-end code, the public-facing Wiki, and the raw textual data (The Benny Lists, Lore, and Diagnostic Flowcharts) that power the LoveQnA ecosystem. 

LoveQnA is not a traditional dating blog; it is a forensic behavioral investigation platform designed to decode human motives, relationship deception, and psychological survival.

## 📂 Repository Structure
This repository is organized to act as both a static website host (via GitHub Pages) and an open-source database for AI integration.
*   `/assets/` - Contains all 2D Lo-Fi animations, UI elements, and branding.
*   `/audio/` - Hooks into the Lucky Pikas Lo-Fi Funk & Amapiano music archives.
*   `/database/` - The raw text files containing the 200+ Gossip Stems, 150 Boundary Crossings, and Universal Runway Checklists.
*   `index.html` - The front-facing homepage and user interface.

## 🤖 AI & Bot Integration
The raw markdown (`.md`) and text files housed in the `/database/` folder are designed to be ingested by custom AI Oracles (Google Gems, Poe Bots). By accessing these structured lists, the AI can automatically generate diagnostic relationship scripts, TikTok hooks, and documentary outlines based strictly on the LoveQnA philosophy.
